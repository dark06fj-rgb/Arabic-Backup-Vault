# Arabic Backup Vault

تطبيق Android مستقل لحفظ ملفات التعريب والملفات العامة محلياً دون الحاجة إلى الإنترنت.

## الوظائف الحالية في الكود

- استيراد ملفات منفردة إلى مساحة خاصة بالتطبيق.
- إنشاء نسخ احتياطية يدوية.
- إنشاء نسخة تلقائية قبل استبدال ملف موجود.
- إنشاء نسخة من الحالة الحالية قبل الاستعادة.
- إنشاء سجل SHA-256 لكل ملف داخل النسخة.
- فحص سلامة النسخ واكتشاف الملفات الناقصة أو المعدلة.
- رفض استعادة النسخ التي تفشل في التحقق.
- استعادة مرحلية مع الاحتفاظ المؤقت بالحالة السابقة أثناء الاستبدال.
- تصدير النسخ بصيغة ZIP.
- استيراد ZIP مع منع مسارات الخروج من مجلد الاستيراد وحدود لحجم وعدد الملفات.

## الخصوصية وحدود الحفظ

- لا توجد صلاحية إنترنت مطلوبة في التطبيق.
- الملفات تبقى في مساحة التطبيق الخاصة.
- حذف التطبيق أو مسح بياناته قد يحذف النسخ المحلية؛ صدّر ZIP إلى مكان مستقل بشكل دوري.
- لا تُرفع ملفات المستخدم إلى GitHub؛ المستودع يحوي كود التطبيق فقط.

## البناء

يتطلب Android Studio وJDK 17 وAndroid SDK 35. افتح المشروع في Android Studio ثم نفّذ Gradle Sync وشغّل وحدة app.

## ما لم يكتمل بعد

- اختبار التطبيق على هاتف Android فعلي.
- دعم الملفات والمجلدات المتداخلة في واجهة إدارة مساحة العمل.
- تحسين الاستيراد الذري للملف المفرد، وإضافة سجل عمليات واضح.
- اختبارات آلية لسيناريوهات تلف النسخ والاستعادة الفاشلة.
- إنشاء APK إصدار بعد نجاح الاختبارات.
