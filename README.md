# Arabic Backup Vault

تطبيق Android مستقل لحفظ ملفات التعريب والملفات العامة محلياً دون الحاجة إلى الإنترنت.

## الحالة الحالية

هذه بداية هيكل التطبيق (نسخة تطوير أولية)، وليست APK جاهزاً أو إصداراً مختبراً على جهاز فعلي.

## الوظائف الموجودة في الهيكل الأولي

- استيراد الملفات من مدير الملفات في Android إلى مساحة عمل خاصة بالتطبيق.
- إنشاء نسخة احتياطية يدوية.
- إنشاء نسخة تلقائية قبل استبدال ملف موجود.
- إنشاء نسخة من الحالة الحالية قبل الاستعادة.
- استعادة نسخة سابقة.
- تصدير النسخ بصيغة ZIP إلى موقع يختاره المستخدم.
- عدم طلب صلاحيات تخزين عامة؛ يستخدم منتقي الملفات الرسمي في Android.

## الخصوصية وحدود الحفظ

- لا توجد اتصالات شبكة مطلوبة في التطبيق.
- الملفات تبقى في مساحة التطبيق الخاصة.
- حذف التطبيق أو مسح بياناته قد يحذف النسخ المحلية؛ لذلك يجب تصدير ZIP إلى مكان مستقل بانتظام.
- لا تُرفع ملفات المستخدم إلى GitHub. المستودع يحوي كود التطبيق فقط.

## البناء

يتطلب Android Studio وJDK 17 وAndroid SDK 35. افتح المشروع في Android Studio ثم نفّذ Gradle Sync وشغّل وحدة app.

## خطة العمل التالية

1. اختبار الاستيراد والاستعادة والتصدير على Android فعلي.
2. إضافة فحص SHA-256 وسجل manifest لكل نسخة.
3. إضافة استيراد ZIP والتحقق من سلامته قبل الاستعادة.
4. إضافة إدارة النسخ وحذفها بعد تأكيد المستخدم.
5. إنشاء APK بعد اجتياز الاختبارات.
